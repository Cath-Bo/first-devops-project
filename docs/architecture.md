# Filozofia DevOps

DevOps to sposób na bardziej uporządkowaną i zautomatyzowaną pracę z programami.

Rozumiem go jako połączenie tworzenia programu, jego uruchamiania i późniejszego 
utrzymania. Zamiast wielokrotnie wykonywać te same czynności ręcznie, staramy się 
je automatyzować i sprawić, żeby można było je łatwo powtarzać.

Ważne jest również rozumienie tego, co dzieje się z systemem, dlatego potrzebne 
są logi, monitoring i możliwość szybkiego znalezienia błędu.

Dla mnie DevOps to przede wszystkim umiejętność zapewnienia stabilnego działania 
programu, bez konieczności ciągłego wykonywania ręcznej pracy przy jego 
utrzymaniu.
